# Vibe Toolbelt

A privacy-first developer toolkit. All processing happens locally in your browser. No data is sent to servers.

## Features

-   **Inspector**: Analyze strings, detect formats (JWT, UUID, Hex, Base64), and calculate entropy.
-   **API Tester**: REST client with collections, history, and code generation.
-   **Media**: Screen recorder with system audio, PiP, and client-side GIF export.
-   **Formatters**: JSON, SQL, and XML formatters/diff tools.
-   **Generators**: UUID, Hash, RSA key, and password generators.
-   **Utils**: CIDR calculator, URL encoder, and image converters.

## Running Locally

```bash
git clone https://github.com/adriandrei/vibe-toolbelt.git
cd vibe-toolbelt
npm install
npm run dev
```
